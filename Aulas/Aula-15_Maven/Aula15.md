## Gerenciador de Dependencias
Usaremos o maven para isso, pom.xml é o gerenciador de dependencias, neste arquivo que adicionamos as nossas dependencias
Maven tem como objetivo simplificar a criação e a distribuição de projetos
Uma funcionalidade do maven é baixar o que precisamos logo quando especificamos o que vamos criar. (Por ex: web App) o maven já adiciona todas as dependencias necessárias
O Gerenciador de dependencias configura a estrutura para contruirmos o projetos
