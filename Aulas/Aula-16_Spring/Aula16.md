## Spring boot
É um framework que visa simplificar o desenvolvimento de aplicativos java.
Facilita muita o desenvolvimento e o trabalho, através também de suas dependencias

## Nesta aula
Iremos desenvolver uma API
### **API:** 
- Interface de Programação de Aplicações, é um conjunto de regras e definições que permite que diferentes softwares se comuniquem entre si
- Propósito: Facilitar a integração entre sistemas, permitindo que devs acessem funcionalidades especificas sem conhecer por completo
- Ajuda a manter o padrão no desenvolvimento

O site da ufn é um grande serviço, um monólito e temos também micro serviços, um sistema mais modularizado
**Como funciona:** A comunicação acontece sempre em dois tempos, A api recebe pedidos e devolve a resposta
Métodos: GET, POST(Cadastrar, enviar dados), PUT(Editar dados), DELETE
